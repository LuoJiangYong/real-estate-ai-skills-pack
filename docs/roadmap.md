# Roadmap

本路线图用于记录 `Real Estate AI Skills Pack` 的长期方向。README 保持简洁，本文件承接后续扩展规划。

## 当前版本

`v0.1.1-alpha`

首发版本已包含：

- `real-estate-strategy`
- `real-estate-storyline`
- `real-estate-community-top-design`

## 近期方向

### 1. 客户研究 Skill

补齐房地产项目最基础的客研能力，支持：

- 客群结构分析
- 客户画像
- 访谈提纲
- 问卷设计
- 客群世界引擎模拟调研双轨验证
- AI种子人群库
- 客户语录提炼
- 需求洞察到产品/营销策略的转译

### 2. 现有 Skill 稳定化

围绕首发 3 个 Skill 做轻量优化：

- 统一 `metadata.json`
- 补充示例输出
- 优化平台无关表达
- 增强脚本跨设备兼容性
- 建立更清晰的知识库索引

### 3. 会员与私域运营 Skill

扩展到房企长期客户经营场景：

- 会员体系设计
- 私域内容节奏
- 用户分层运营
- 权益体系
- 转介绍与复购机制

## 中期方向

### 1. 老带新 / 全民推荐机制 Skill

面向营销转化和客户裂变，沉淀：

- 推荐机制设计
- 激励模型
- 推荐话术
- 转化漏斗
- 数据评估指标

### 2. 商业与社区配套运营 Skill

覆盖社区商业、会所、自营空间和配套运营：

- 空间定位
- 品牌引入与自营选择
- 内容运营
- 收入模型
- 运营评估

### 3. 房地产项目视觉渲染与分析图 Skill

类别定位：设计表达与视觉转译类 Skill。

该 Skill 将作为未来独立 Skill 开发，面向房地产项目推广、方案汇报和设计沟通场景，基于已有项目效果图、实拍图、SU 软件截图、建筑图、景观图、户型图等素材，生成不同风格的效果图、风格图和演绎分析图。

能力方向一：效果图 / 风格图再生成

- 夜景、黄昏、水汽、雨后、鸟瞰等氛围风格转译
- 建筑立面、景观、会所、商业街区等场景风格强化
- 材质、灯光、色彩、构图和镜头语言调整
- 面向推广、提案、汇报和项目演示的视觉方案生成

能力方向二：演绎分析图 / 设计表达图

- 建筑多角度一致性分析
- 彩平图、区位分析图、流线分析图
- 建筑体块分析图
- 平立剖三视图表达
- 日照、风环境等分析表达图
- 景观结构、视线、轴线、价值点拆解图

维护边界：

- 输出用于创意表达、方案沟通、推广演示和初步分析表达
- 不替代设计院、建筑师、规划顾问或专业仿真软件的正式结论
- 涉及日照、风环境、结构、消防、规划合规等内容时，应以专业软件和权威审查结果为准

### 4. 跨 Skill 案例索引

逐步建立统一案例索引，让故事线、产策、社群、会员等 Skill 可以共享案例资产，但保持各 Skill 独立运行。

## 长期方向

项目长期目标是形成覆盖中国房地产市场核心工作链路的 AI Skill Pack：

- 客研
- 投前研判
- 产策定位
- 产品价值体系
- 品牌故事线
- 房地产项目视觉渲染与分析图
- 营销推广策略
- 媒体内容策略
- 私域与会员运营
- 社群运营顶层设计
- 老带新与全民推荐机制
- 商业与社区配套运营

## 维护原则

- 高内聚：一个 Skill 解决一个明确问题。
- 低耦合：每个 Skill 尽量独立运行。
- 可扩展：新增业务场景优先新增 Skill，而不是塞进旧 Skill。
- 易维护：版本、案例、脚本、方法论分层管理。
- 高效简洁：非必要不复杂化。
