## 1. 越秀地产 — 爱越聚乐部 / YE CLUB【深度版】{#越秀深度}

> 本案例基于越秀公开资料及克而瑞研究报告，是目前库中最完整的一手案例。

### 1.1 战略起点：六个追问

越秀在2021年启动社群体系时，内部提出了六个根本性追问：
1. 巨大投资成本的示范区除了是销售道具还可以是什么？能不能是书局、美术馆、生活方式品牌？
2. 前期商业氛围打造是不是只有花钱引入外部的路？能不能是自营品牌沉淀？
3. 空间配套投入是不是一定会沦为运营的烫手山芋？会不会有另外一种算账方式？
4. 社群是不是就是包装活动和拉微信群发福利？如何持续给客户提供生活方式解决方案？
5. 品质竞争时代产品和服务如何更深入人心？除了高大上的物理空间，还可以有什么？
6. 项目全周期的重复投入，如何进一步沉淀？如何形成成果品牌并进一步复制？

**启动背景**：
- 2021年，基于《社群民意与未来生活场》客研（覆盖43000+业主、28+机构/主理人）
- 公司总部牵头，明确"品牌建设+能力沉淀+业务协同"三位一体定位
- 2021年11月~2024年，用800天试点，探索新可能

### 1.2 平台架构："1+N"社群运营矩阵

```
爱越聚乐部（统一运营品牌）
├── 线上内容社区（爱越聚乐部小程序）
├── 线下社群空间（樾+系列自营品牌）
│   ├── 樾咖啡 Cafe
│   ├── 樾书局 Book
│   ├── 樾艺术商店 Artstore
│   ├── 樾+Space（文化艺术旗舰）
│   └── 樾+社群之家（2025年示范建设）
├── 系列内容IP
│   ├── 了不起的小新星（第五季，覆盖28000+家庭）
│   ├── 越秀社区节（2025年首届）
│   └── 生活方式刊物《樾+·河流上的成都》
└── 生态共建计划 Knock Knock
    └── 越秀生活合伙人体系（2025年推出）
```

### 1.3 组织机制：双轮驱动

**双轮模型**：
- **统筹轮**：客户关系中心统筹顶层设计，跨职能社群运营组织
- **落地轮**：各单位/区域保留个性化落地灵活性

**机制工具**：月度协同会议 + 底层运营工具 + 运营标准

**成果**："总部标准化 + 落地个性化"，形成飞轮效应

**广州区域个性化社群产品**（总部品牌体系下）：
- 山下聚（融合景观）、人文汇（人文社群）、临江社（江景社群）、烟火集（老城社群）
- 圈层社群：臻朋友圈、榕樾生活、席地湖畔

### 1.4 空间运营四维体系

#### 维度一：空间产品化

**自营生活方式品牌矩阵（樾+系列）**：

| 品牌 | 定位 | 落地情况 | 数据 |
|------|------|---------|------|
| 樾+Space | 文化艺术实验空间，策展型旗舰 | 2023.11首开ICC灰空间 | Award360°年度商业品牌，首展参观3357人，媒体声量250W+ |

1. 社群主理人（社群自治）

3. 社区提案官（配套运营共创）
4. 生活创作者（内容生产共创）

联动越秀多元产业：地产+商业+酒店+零售+食品+农牧+交通+产业园

#### 维度四：社群会员化

**爱越聚乐部小程序**（2024年下半年试点上线）：
- 核心功能：线上内容社区+活动票务+会员权益+空间预约+话题互动
- **系统集成**：全面打通越秀会员体系（悦秀会）+ 营销线索中心 + 多元业态
- **上线首年：新增核心用户30000+，日均活跃600+**

### 1.5 发展阶段路径（内部战略版四阶段）

| 阶段 | 定位 | 核心任务 | 发展目标 |
|------|------|---------|---------|
| **1.0 短期** | 生长发展 | 主体搭建、解题能力底座、经营闭环 | 更多人认知×互动×认可 |
| **2.0 中期** | 声量积累 | 打磨产品服务、沉淀核心竞争力和品牌护城河 | 更多人信赖×融入 |
| **3.0 长期** | 平台力 | 平台力输出、内部协同、外部增量 | 更多人分享×共建 |
| **4.0 终局** | 品牌输出 | 具有品牌影响力的平台对外输出 | 行业标杆，能力输出 |

**4大维度行动策略**（内部战略原文）：
01. 社群文化主体公司筹建 + 运营能力培育 + 资源平台搭建
02. 社群空间自营品牌体系搭建 + 空间/内容/经营打版
03. 社群线上平台完善 + 内容生态 + 获客场景
04. 内容强IP矩阵孵化 + 产品化打造探索 + 内容营销

### 1.6 长效评估体系（2025年建立）

### 1.8 方法论总结

| 要素 | 越秀做法 | 核心价值 |
|------|---------|---------|
| **命名策略** | 谐音+中英双轨（爱越聚乐部/YE CLUB） | 品牌识别×格调兼顾 |
| **组织机制** | 总部标准化+属地个性化双轮驱动 | 规模化落地可复制 |
| **空间策略** | 自营品牌孵化（樾+系列），降低20%成本 | 从外部引入到自营资产沉淀 |
| **生态策略** | Knock Knock共建+越秀生活合伙人体系 | 共益机制，降低运营成本 |
| **系统集成** | 小程序打通CRM+物业+会员+销售 | 社群直接赋能营销转化 |
| **内容策略** | IP产品化（小新星第五季）+刊物+节事 | 内容即获客，品牌即产品 |
| **可持续性** | 自营品牌内部市场化孵化→标准化→输出 | 运营能力资产化，形成护城河 |

```

├── A4美术馆文化集群（2014年起）
│   └── A4美术馆 / A4国际驻留 / A4X艺术中心 / A4儿童馆
├── 寻麓书馆（2019年，动态人文交流平台）
│   └── 举办400+场，100+嘉宾，4万+读者
├── A8设计中心（2019年，泛文化设计平台）
├── a7 Creator Lab·阿发奇（2021年，内容创意平台+主理人基金）
│   └── MEWS马厩青年文化空间（立体杂志式内容空间）
├── LOOKLIVE（2021年，音乐戏剧现场表演机构）
├── 麓客社创中心（2022年，民办非企业，2023年独立创收超100万）
```

### 关键数据

- 2023年：130+社群，年活动1100+场
- 麓客+城市创想礼：与1100+品牌主理人共创

### 活动价值模型（7层评价）
```
1. 活动本身
2. 参加人数（新人占比）
3. 参加者满意度
4. KOL/社区积极分子挖掘
5. 社区组织培育
6. 价值观传递
7. 蓝图推进（满足居民对美好生活的向往）
```

### 治理架构（三层）
- **麓湖社区发展基金会**：公益主体，支持社群发展、环保、教育
- **麓客社创中心**：社群组织化，社区节日运营，空间运营
- **麓客社群联合会/麓湖共益会**：居民自治组织

### 方法论提炼

## 3. 阿那亚 — 生活方式品牌社群 {#阿那亚}

### 背景
- 开发商：华彬集团阿那亚
- 项目布局：秦皇岛（主力）+ 崇礼、金山岭、三亚、广州九龙湖
- 定位：**"中国最具情感价值和精神价值的生活方式品牌"**

### 品牌公式
**观念×产品×服务×社群×内容 = 生活方式品牌**
- 观念：以价值观筛选客户（"人生可以更美"）
- 产品：精神地标串联精神主轴（孤独图书馆/礼堂/沙丘美术馆/剧场）
- 服务：运营和生活方式服务
- 社群：三代演进（客诉→议事+兴趣→情感共同体+事业合伙人）
- 内容：节事IP矩阵（戏剧节/音乐节/海报节/大地艺术节）

### 社群三代演进模型

| 阶段 | 触发背景 | 特征 |
|------|---------|------|
| 1.0 | 2014年一期客诉，村长亲自管群500人 | 9大业主群，公共议事平台 |
| 2.0 | 社区公共生活需求增长 | 百余兴趣社群，社区议事 |
| 3.0 | 头部社群IP化 | 情感共同体+事业合伙人，商业闭环 |

### 内容产品矩阵
阿那亚戏剧节 / 音乐节 / 生活节 / 海报节 / 大地艺术节 / 海浪电影周 / 播客派对 / 国际影像艺术展 / 冲浪节 / 马术节

### 独立主体架构
- 阿那亚文化艺术 + 阿那亚影视文化（内部独立主体）
- 品牌孵化：卷宗书店、%咖啡、单向空间、理想国等

### 方法论提炼
| 要素 | 阿那亚做法 |
|------|---------|
| 精神锚点 | "孤独而不孤单" — 精准击中高净值精英痛点 |
| 内容战略 | 用文化IP建立精神高地，内容体验前置不是后期包装 |
| 社群公约 | 《业主公约》《访客公约》《宠物公约》《民宿公约》 |
| 传播裂变 | 老带新占比超60%，每个业主都是品牌传播者 |
| 核心启示 | 文化艺术是阿那亚面向未来的生活解决方案和商业模式 |

## 5. 时代中国 — 时代趣乐部 {#时代}

> 本案例包含时代中国社群命名思考，是目前库中唯一完整记录**命名推导过程**的一手文件。

### 背景
- 开发商：时代中国（广州本土，城市更新领域领先）
- 社群品牌：**时代趣乐部**（2019年命名确定）
- Slogan：**"有趣的人都在时代相遇"**
- 核心诉求：城市中端客群的趣味生活感知与日常对抗孤独

### 命名的底层洞察（原文）

> "人们有各种需求和爱好，工作、篮球、瑜伽、烘焙、阅读等等，说是打发时间也好，找乐子也罢，其实都是在对抗生活本身固有的无聊。而城市生活更容易趋向常态，忘了生活原本是千姿百态的。所以人们渴望有趣，让生活不那么常规。我们，既寻找有趣的灵魂，也塑造有趣的自己。"

**关键判断**：社群名要体现**"人"的心声**，而不是开发商的服务视角。

### 命名方案推导（完整逻辑链）

**竞品分析与反思**：
- 东原"原·聚场"：品牌字根"原"+聚场实体空间，强调"开发商为社区所做"
- 华远"Hi平台"：服务平台视角，以开发商角度出发
- 时代团队判断：**以上均从开发商视角强调，缺乏"人的心声"**

**推导过程**：
```
洞察：城市业主渴望有趣，渴望打破日常常规，对抗孤独
        ↓
价值主张：时代正是创造有趣欢乐生活体验的地方
        ↓
关键情感词：趣 + 乐 + 部（Club感）
        ↓
品牌名：时代趣乐部
        ↓
Slogan验证："有趣的人都在时代相遇" ✓
（以"人"为主语，而非"时代为你做了什么"）
```

### 品牌视觉体系

**视觉语言**：白描人物造型 + 铭黄色对撞
- 白描：亲民、平易近人、有独特性
- 铭黄：活泼、充满趣味、视觉冲击力强
- 整体：具有戏剧性画面感，与竞品清新柔和风格形成差异

**VI延展**：饮用水包装、围裙设计、便当盒、马克杯、口袋袋、趣味礼品包装
——品牌渗透到日常生活道具，强化"趣味"调性

**广告文案风格**（趣味自嘲型）：
- "换过很多广场，依然跳不好这支舞"（广场舞社群）
- "当一辆好车遇到一个坚强的屁股"（骑行社群）
- "本来想去夜跑，结果遇到烧烤"（跑步社群）

### 后续演变
时代趣乐部后来迭代为**时代美好社**，Slogan从"有趣"转向"美好"，反映品牌随市场成熟从年轻活力调性转向更普世的"美好生活"定位。

### 内容刊物
持续出版《**生活艺术家**》杂志，沉淀品牌文化资产，是少数坚持内容刊物输出的城市型社群品牌之一。

### 方法论提炼

| 要素 | 时代做法 | 启示 |
|------|---------|------|
| **命名起点** | 从业主的内心渴望出发，而非开发商服务视角 | 命名要说"人话" |
| **价值主张** | "有趣"精准击中城市中产对日常常规的反叛 | 找到目标客群的"痛感"词 |
| **视觉突破** | 铭黄+白描造型，拒绝行业惯常的清新柔和 | 视觉差异化是品牌记忆的关键 |
| **文案策略** | 趣味自嘲，说人话，接地气 | 社群内容不必高大上，有共鸣才有传播 |
| **品牌延展** | 日常生活道具全面植入VI | 让品牌成为业主日常生活的一部分 |

## 11. 越秀地产运营机制深度拆解（2025年最新）{#越秀机制}

### 11.1 客户全生命周期节点与社群落地对应

越秀将客户周期分为以下阶段，社群运营随客户周期分工落地：

| 客户阶段 | 周期节点 | 主责团队 | 费用归口 | 社群价值目标 |
|---------|---------|---------|---------|------------|
| 蓄客/持销期 | 蓄客→准1/2/3 | **营销为主** | 营销费用 | 存量转化、客户挖潜、项目导客 |
| 准业主/交付期 | 准3→磨1/2 | **客关(客协)为主** | 悦秀会费用 | 老带新转化、客户粘性、客户忠诚度 |
| 老业主期 | 老1/2/3及以后 | **物服为主** | 物业社区文化费用 | 收缴率、增值服务、客户满意度 |

**核心机制**：客关(客协)牵头，协同营销、物业、生产、品牌、数智等条线，打造统一品牌运营体系。

### 11.2 客户关系漏斗模型（陌生人→家人）

```
陌生人（外在流量池）
    ↓ [认识接触]
熟人（潜在客户/社群会员/粉丝）
    ↓ [转化参与]
朋友（品牌核心认同粉丝/高粘性客户）
    ↓ [推荐&高度认同]
家人（复购业主/涟漪影响者）
    ↓ [增值服务]
媒体邀约（品牌传播关键人）
```

**涟漪模式**：通过业主/朋友口碑传递，实现品牌软实力扩散，触达外在流量池。

## 10. 典型失败/误区提炼 {#误区}

根据越秀内部战略文件，以下是常见的社群运营误区：

1. **后期包装思维**：社群运营大多用于后期暖场/引流，未前置到产策阶段
2. **散落投入**：各单位分散投入，无统一平台沉淀，销售注意力转移后成果即流失
3. **外部引入依赖**：前期商业/艺文配套均靠外部品牌引入，费用高且品牌资产归外方
4. **未建章立制**：工作机制未形成规范体系，各区域运营成熟度不一
5. **无经营闭环**：有活动没数据，有口碑没转化，缺乏长效评估模型
6. **单向输出**：社群运营是企业单向输出，未建立业主共创共益机制，可持续性差
