### 2. NPS 净推荐值体系

**标准问卷**：
>"您有多大可能向朋友或家人推荐[企业品牌]的社群活动/品牌？请打分（0-10分）"

**分级标准**：
- 9-10分：推荐者（Promoter）
- 7-8分：被动者（Passive）
- 0-6分：贬损者（Detractor）
- **NPS = 推荐者% - 贬损者%**

**NPS评估机制**：
- 评估对象：年度覆盖客户（问卷发放）
- 覆盖范围目标：线上化60%以上
- 评估维度：社群覆盖客户NPS vs 整体项目NPS（对比分析社群价值）

**行业参考基准**：
| NPS区间 | 评级 | 说明 |
|---------|------|------|
| 70+ | 卓越 | 麓湖、阿那亚等头部项目水平 |
| 50-69 | 良好 | 竞争力较强 |
| 30-49 | 一般 | 需要改进 |
| 0-29 | 较差 | 客户体验不佳 |
| 负数 | 差 | 批评者多于推荐者 |

## 二、运营健康度诊断：三阶段判断标准

根据案例实测，将项目/区域社群运营分为三个阶段：

| 阶段 | 判断标准 | 代表区域 | 重点任务 |
|------|---------|---------|---------|
| **体系导入期** | 主理人<20人，活动<50场/年，自发活动占比<30% | 建体系、建工具、找主理人 |
| **社群发展期** | 主理人≥20人，活动≥100场/年，主理人发起>50% | 固化IP、深化共创、降本增效 |
| **社群生态期** | 社群自组织运营，公司投入持续下降，NPS显著提升 | 麓湖/阿那亚水平 | 平台化、对外输出 |

## 三、投入产出测算模板

**全国社群运营模型**（45个项目，26人兼岗）：

| 项目 | 2025年实测 | 2026年目标 |
|------|---------|---------|
| 总投入 | 140.6万元 | 持平 |
| 场均成本 | 0.4万元 | 0.34万（↓15%） |
| 项目平均费用 | 1.09万元 | 0.98万（↓10%） |
| 助力成交 | 1.55亿元 | 1.7亿（↑10%） |
| 推荐成交 | 0.61亿元 | 持续提升 |
| **直接投资回报比** | **1:110**（1.55亿/140.6万）| 提升 |
| **含推荐总回报比** | **1:154**（2.16亿/140.6万）| 提升 |

**主理人降本价值测算**：
- 142位主理人，激励成本约6.4万元/年（450元×142人）
- 主理人发起活动占54%（约188场），平均降本30%
- 按场均0.4万×188场×30%降幅 = **节省22.6万元运营成本**
- 主理人ROI：22.6万节省/6.4万激励成本 = **3.5倍**

**单项目社群运营参考**：
- 区域：22.3万/14个项目 = 平均**1.6万/项目/年**

### 2. 客户转化归因模型

**漏斗结构**：

```
社群会员总数
    ↓ [触达率]
了解在售项目的社群会员
    ↓ [意向率]
产生购买意向（报备）
    ↓ [到访率]
实际到访售楼处
    ↓ [成交率]
完成购房（成交）
```

**数据采集要求**：
- 社群平台与销售CRM系统打通
- 会员手机号作为唯一ID跨系统匹配
- 每月生成社群贡献业绩报告

**核心指标**：
| 指标 | 计算公式 | 参考目标 |
|------|---------|---------|
| 社群获客成本（CPL） | 社群运营总费用 ÷ 社群带来的报备数 | 比渠道成本低30%+ |
| 社群转化率 | 社群成交数 ÷ 社群报备数 | 行业平均10-15% |
| 社群业绩贡献率 | 社群成交金额 ÷ 总销售额 | 目标10-20% |

### 3. 全民推荐裂变评估

**裂变行为定义**：
- **一级推荐**：业主直接推荐，带来新客户报备
- **二级推荐**：被推荐人再次推荐，形成裂变链条

**评估指标**：
| 指标 | 说明 |
|------|------|
| 推荐渗透率 | 产生推荐行为的业主数 ÷ 社群会员总数 |
| 推荐转化率 | 推荐成交数 ÷ 推荐报备数 |
| 人均推荐价值 | 推荐成交总额 ÷ 产生推荐的业主数 |
| 推荐成本比 | 推荐激励费用 ÷ 推荐带来的销售额（目标<3%） |

### 4. 品牌商业价值评估

**维度一：媒体传播价值（MV）**
- 社群活动媒体曝光量（折算广告价值）
- 业主UGC内容（小红书/微博/抖音）传播指数
- 行业媒体、设计媒体主动报道价值

**维度二：品牌溢价能力**
- 同区域竞品价格对比下的单价溢价
- 去化速度对比（社群城市 vs 非社群城市）
- 业主接受度调查（是否因社群文化选择该品牌）

**维度三：品牌资产增值**
- 品牌知名度/美誉度年度变化
- 品牌关键词搜索量增长
- 第三方品牌价值评估机构的评级变化

## 三、投入产出测算模板

### 年度预算参考模型（以中型房企为例）

**基础版（年预算 300-500万）**：
| 预算项目 | 占比 | 金额参考 |
|---------|------|---------|
| 社群运营团队（3-5人） | 35% | 105-175万 |
| 年度活动（4-6场） | 30% | 90-150万 |
| 内容生产（刊物/视频/KOL） | 15% | 45-75万 |
| 平台系统运营维护 | 10% | 30-50万 |
| 空间改造/运营（社群之家） | 10% | 30-50万 |

**成熟版（年预算 800-1500万）**：
| 预算项目 | 占比 | 金额参考 |
|---------|------|---------|
| 社群运营团队（8-15人） | 30% | 240-450万 |
| 年度活动（10-15场含旗舰） | 30% | 240-450万 |
| 内容生产（多媒体矩阵） | 15% | 120-225万 |
| 平台系统运营升级 | 10% | 80-150万 |
| 空间运营（多点） | 10% | 80-150万 |
| 主理人激励/生态建设 | 5% | 40-75万 |

### ROI测算逻辑

```
社群ROI = 社群直接产出价值 ÷ 社群运营总投入

直接产出价值 = 
  社群带来的成交金额 × 3%（佣金当量）
  + 省去的渠道费（社群客替代渠道客 × 渠道费率差）
  + 媒体传播价值
  + 物业增值服务收入增量
  
目标ROI：≥ 3:1（即每投入1元，产出价值≥3元）
```
